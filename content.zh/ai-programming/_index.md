## 模型与工具选型：先决定用什么

1. **选模型**：看能力边界与 Token 成本
2. **选工具**：IDE / 插件 / Agent CLI
3. **选接入方式**：订阅套餐、中转站或 API 聚合
4. **控成本**：同样任务尽量少烧 Token
